# 六花 · Coopanion 桌宠形象包

一个二头身的六花：黑色短发、右边一缕细细的侧马尾、头顶一根呆毛；
右眼戴着眼罩（邪王真眼），左手缠着绷带。

## 安装

1. 下载 Releases 里的 `rikka-chibi-v0.1.0.zip`（不用解压）。
2. 打开 Coopanion → 「装扮」→「形象」→ 「导入」，选中这个 zip。
3. 导入完成后，在形象列表里选「六花 · 新骨架」。

也可以导入解压出来的 `rikka-chibi` 文件夹。

## 内容

- 19 种表情：平静、开心、眨眼、喜欢、害羞、惊讶、生气、难过、犯困、思考、
  得意、嘟嘴、担心、认真、慌张、害怕、期待、大哭、疑惑。
- 18 种动作：站起、跳、小跳、张望、转身、点头、摇头、转圈、坐下、睡觉、
  晕、走走、跑、招手、鞠躬、发抖、扑腾、跳舞。
- 支持光标视线、自然眨眼、说话口型、倾听、思考、拎起与抛落。
- 只有一套配色「邪王真眼」，主题色是紫色（`#7C5CD6`）。
